# GMP Store — δοκιμαστική προεπισκόπηση

**Κατάσταση:** στατική, λειτουργική επίδειξη σχεδίου. Δεν είναι ενεργό ηλεκτρονικό κατάστημα.

## Τι περιλαμβάνει

- Μαύρο/χρυσό σχέδιο για κινητό και υπολογιστή, με φωτογραφικό υλικό της εγκεκριμένης μακέτας.
- 9 κατηγορίες και 12 **ενδεικτικά** προϊόντα με υποθετικές τιμές.
- Λειτουργική αναζήτηση, φίλτρα, ταξινόμηση, αγαπημένα, καλάθι επίδειξης και λεπτομέρειες προϊόντος.
- Ελληνικά και αγγλικά, επιλογή χώρας και δοκιμαστικό βοηθό αναζήτησης με απλούς κανόνες (χωρίς σύνδεση σε τεχνητή νοημοσύνη).
- Τα αγαπημένα, το καλάθι και οι προτιμήσεις αποθηκεύονται μόνο τοπικά στο πρόγραμμα περιήγησης.
- Δεν υπάρχουν λογαριασμοί, αποστολές, πληρωμές, πραγματική σύνδεση προμηθευτών ή επεξεργασία παραγγελιών.

## Άνοιγμα από το Termux

1. Κατέβασε το αρχείο `gmp-store-demo.zip` στον φάκελο «Λήψεις» του κινητού.
2. Άνοιξε το Termux, δώσε πρόσβαση στα αρχεία (μία φορά) και πληκτρολόγησε:

```sh
termux-setup-storage
pkg update -y
pkg install python unzip git gh -y
cd ~
unzip -o ~/storage/downloads/gmp-store-demo.zip -d ~
cd ~/gmp-store
python -m http.server 8080 --bind 127.0.0.1
```

3. Άνοιξε στον φυλλομετρητή του **ίδιου κινητού** το `http://127.0.0.1:8080/`.
4. Ο διακομιστής τερματίζεται με **Ctrl+C** στο Termux. Για επανεκκίνηση αρκούν οι δύο τελευταίες εντολές.

Αν η θύρα 8080 χρησιμοποιείται, άλλαξε το 8080 σε 8081 τόσο στην εντολή όσο και στον σύνδεσμο.

## Δημιουργία αποθετηρίου GitHub μέσω Termux

Το GitHub ζητά εξουσιοδότηση μία φορά. **Μη μοιράζεσαι κωδικούς ή διακριτικά.**

```sh
cd ~/gmp-store
gh auth login --web -p https
gh auth setup-git
git init -b main
git config user.name "$(gh api user --jq .login)"
git config user.email "$(gh api user --jq .id)+$(gh api user --jq .login)@users.noreply.github.com"
git add .
git commit -m "Initial GMP Store demo"
gh repo create gmp-store --public --source=. --remote=origin --push
```

Η παραπάνω εντολή επιχειρεί να δημιουργήσει **δημόσιο** νέο αποθετήριο. Αν υπάρχει ήδη αποθετήριο με το ίδιο όνομα, χρησιμοποίησε άλλη ονομασία ή ανέβασέ το στο υπάρχον με `git remote` και `git push`.

**Προσοχή:** Ένα δημόσιο αποθετήριο και η ιστοσελίδα GitHub Pages είναι προσβάσιμα από όλους. Κανένα προσωπικό δεδομένο ή κωδικός δεν περιλαμβάνεται στο πακέτο.

## Ενεργοποίηση GitHub Pages

1. Άνοιξε το αποθετήριο στο GitHub από τον φυλλομετρητή του κινητού.
2. Πάτησε **Settings → Pages** (ενδεχομένως στο μενού `...`).
3. Στο **Build and deployment → Source**, διάλεξε **Deploy from a branch**.
4. Στο **Branch**, διάλεξε **main** και **/(root)** και πάτησε **Save**.
5. Το GitHub θα εμφανίσει σύνδεσμο της δημόσιας δοκιμαστικής ιστοσελίδας μόλις ολοκληρωθεί η δημοσίευση.

Η δημοσίευση είναι μόνο για **προεπισκόπηση**, όχι για εμπορική λειτουργία.

## Επόμενα απαραίτητα πριν από πραγματική λειτουργία

Επιλογή και έλεγχος προμηθευτών και προϊόντων, νομικές/φορολογικές απαιτήσεις, διαχείριση επιστροφών και αποστολών, ενημερωμένες πολιτικές, παραγωγική υποδομή παραγγελιών, ασφαλείς πληρωμές και έλεγχοι συμμόρφωσης ανά χώρα.
