# GMP Store — δεύτερη δοκιμαστική έκδοση

Η αρχική έκδοση για κινητά λειτουργεί χωρίς κύλιση: σταθερή κεφαλίδα, αναζήτηση, πέντε οθόνες και κάτω μπάρα πλοήγησης. Δεν υπάρχουν πραγματικές παραγγελίες ή πληρωμές.

## Περιεχόμενο

- Μαύρη/χρυσή εμφάνιση και υδρόγειος από το εγκεκριμένο σχέδιο.
- 10 **χειροκίνητα μεταφρασμένες** γλώσσες περιβάλλοντος: ελληνικά, αγγλικά, γερμανικά, γαλλικά, ισπανικά, ιταλικά, πορτογαλικά, ολλανδικά, ιαπωνικά και αραβικά.
- Επιλογή γλώσσας από τη ρύθμιση γλώσσας του φυλλομετρητή κατά την πρώτη επίσκεψη, χωρίς γεωεντοπισμό ή πρόσβαση σε προσωπική τοποθεσία. Αν δεν υποστηρίζεται η γλώσσα, η προεπιλογή είναι τα αγγλικά. Ο χρήστης μπορεί να αλλάξει γλώσσα χειροκίνητα.
- Οι τίτλοι και οι περιγραφές **προϊόντων** δεν μεταφράζονται αυτόματα: εμφανίζονται οι γλωσσικές εκδόσεις που δημοσιεύει ο ιδιοκτήτης και, εάν απουσιάζουν, το πρωτότυπο.
- Ο κατάλογος `data/products.json` αρχίζει εντελώς **άδειος**. Κανένα προϊόν δεν δημιουργείται, συγχρονίζεται ή δημοσιεύεται αυτόματα. Μόνο εγγραφές με `published: true` εμφανίζονται.
- Οι φωτογραφίες κατηγοριών είναι διακοσμητικές· **δεν αποτελούν διαθέσιμα προϊόντα**.
- Τα αγαπημένα και το δοκιμαστικό καλάθι φυλάσσονται τοπικά στη συσκευή του επισκέπτη.
- Η επιλογή χώρας είναι ενημερωτική. Δεν υπάρχει ακόμη συνεργασία προμηθευτών, πραγματικός έξυπνος βοηθός ή πληρωμές.

## Εγκατάσταση / δοκιμή στο Termux

Κατέβασε το αρχείο `gmp-store-v2.zip` στις Λήψεις του κινητού. Εάν είχες την παλιά έκδοση, κάνε αντίγραφο ασφαλείας πριν την αντικατάσταση:

```bash
termux-setup-storage
pkg install python unzip git gh -y
cd ~
[ ! -d gmp-store ] || cp -a gmp-store "gmp-store-backup-$(date +%Y%m%d-%H%M%S)"
unzip -o ~/storage/downloads/gmp-store-v2.zip -d ~
cd ~/gmp-store
python -m http.server 8080 --bind 127.0.0.1
```

Άνοιξε από το κινητό `http://127.0.0.1:8080`.

## Προσθήκη προϊόντος μόνο από τον ιδιοκτήτη

Το εργαλείο δουλεύει **τοπικά στο Termux**, δεν υπάρχει δημόσια φόρμα διαχείρισης:

```bash
cd ~/gmp-store
python tools/products.py add
python tools/products.py list
python tools/products.py publish gmp-TO_ID_SOU
```

Αντικατάστησε το `gmp-TO_ID_SOU` με το πραγματικό αναγνωριστικό που εμφανίζει το εργαλείο. Τα νέα προϊόντα δημιουργούνται ως μη δημοσιευμένα (`published: false`). Επίλεξε ο ίδιος πότε θα δημοσιευτούν. Για απόκρυψη: `python tools/products.py hide ΤΟ_ΑΝΑΓΝΩΡΙΣΤΙΚΟ`. Για να προσθέσεις ελεγμένη μετάφραση π.χ. στα γερμανικά: `python tools/products.py translate ΤΟ_ΑΝΑΓΝΩΡΙΣΤΙΚΟ --lang de --name 'Mein Produkt' --description 'Produktbeschreibung'`. Οι μεταφράσεις προϊόντων προστίθενται μόνο από εσένα, όχι αυτόματα.

## Ανέβασμα στο **ίδιο** αποθετήριο GitHub

Αφού ελέγξεις τη σελίδα τοπικά και έχεις ήδη το υπάρχον αποθετήριο στο `~/gmp-store`, εκτέλεσε:

```bash
cd ~/gmp-store
bash tools/publish.sh
```

Το πρόγραμμα χρησιμοποιεί το υπάρχον ιστορικό Git, κάνει ενημέρωση, απομακρύνει μόνο τις παλιές εικόνες των έξι ενδεικτικών προϊόντων και δεν κάνει ποτέ `git push --force`. Εάν λείπει η σύνδεση ή το υπάρχον αποθετήριο, σταματά χωρίς επικίνδυνες αλλαγές. Για κάθε νέα δημοσίευση προϊόντος, επανάλαβε `bash tools/publish.sh`.

Η δημόσια διεύθυνση μετά τη δημοσίευση είναι `https://moschidismoschos-hash.github.io/gmp-store/`.
